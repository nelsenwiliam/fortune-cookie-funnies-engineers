A one-line fortune cookie message for a software engineer, written by a tiny pure-stdlib Python program. The fortune it writes:

> Your future self will read this code at 3 a.m. and forgive you. Leave a comment.

## Run it

```sh
python3 main.py
```

That writes the fortune to `/output/entry.txt` (one line, 80 characters, UTF-8).
